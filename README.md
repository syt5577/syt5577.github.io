📌 项目简介
本项目旨在解决企业内部项目进度月报人工审查效率低、标准不统一、漏项难发现的问题。通过自动化合并多部门 Excel 报表、调用大模型（LLM）进行智能审查、并按问题类型自动分发邮件通知责任人，将每月 2 人天的工作量压缩至 10 分钟，问题检出率提升 40% 以上。

🎯 背景
在项目管理中，每月需要收集各职能部门（采购、辅助、机动等）填写的项目进度 Excel，人工对比上月与本月描述，判断是否存在漏项、停滞、敷衍等情况。这种方式存在以下痛点：

耗时费力，容易遗漏；

审查标准不统一，依赖个人经验；

问题发现后需手动通知责任人，沟通成本高。

本系统实现了从数据合并、AI 审查到邮件通知的全流程自动化。

✨ 核心功能
多部门 Excel 自动合并：读取基准文件（含上月进度）和各部门提交的本月进度文件，以项目名称为键合并数据。

智能进度审查：调用 Dify 工作流，利用 LLM 对比上下月进度，生成符合规则的审查建议（漏项预警、停滞预警、敷衍预警、进度清晰）。

动态通知部门判断：LLM 根据问题内容自动判断应通知的部门（如采购问题→采购部，施工问题→主责部门），支持多部门同时通知。

合并邮件发送：按部门汇总项目，生成 HTML 表格邮件，通过 SMTP 自动发送给对应责任人（仅发送包含“预警”的项目）。

测试模式：可配置只处理前 N 个项目，便于调试。

结果存档：生成带时间戳的 Excel 文件，包含所有项目的审查建议和通知部门信息。

🛠️ 技术栈
Python：pandas（数据处理）、requests（API 调用）、smtplib（邮件发送）

Dify：工作流编排、LLM 调用、提示词工程

大模型：通过 Dify 接入（如 GPT-3.5、通义千问等）
